| 작업 유형         | 추천                  | 이유                  |
| ------------- | ------------------- | ------------------- |
| 신규 프로젝트 생성    | **App**             | 전체 구조 설계부터 구현까지 관리  |
| 신규 대규모 기능 개발  | **App**             | 여러 작업을 분리하고 병렬 진행   |
| 아키텍처 변경       | **App**             | 영향 범위 분석 및 작업 관리    |
| 기존 기능 개선      | **Extension**       | IDE에서 코드를 확인하며 수정   |
| 버그 수정         | **Extension**       | 문제 코드와 실행 흐름을 바로 확인 |
| 간단한 리팩터링      | **Extension / CLI** | 빠르게 작업 지시 가능        |
| 테스트 코드 추가     | **Extension / CLI** | 특정 코드나 모듈을 대상으로 작업  |
| 빌드·테스트 자동화    | **CLI**             | 스크립트와 CI/CD 통합      |
| 반복적인 대량 코드 변경 | **CLI**             | 명령어 기반 자동화에 적합      |
- 어차피 세션이 길어지면 문서화 이후 새 새션을 시작하는게 토큰소비에 유리함

|상황|권장 방식|
|---|---|
|잠시 종료했다가 같은 작업 계속|기존 세션 재개|
|같은 기능의 버그 수정 계속|기존 세션 재개|
|완전히 새로운 기능 개발|새 세션|
|기존 대화가 지나치게 길어짐|작업 상태를 문서화하고 새 세션|
|다른 인터페이스로 이동|세션 재개 지원 확인 후 이동|
