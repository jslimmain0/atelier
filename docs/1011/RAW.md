AI는 검색엔진과 같다

1. 안에 알고리즘을 모른다. 근데 원하는걸 찾기위해 여러가지 키워드를 써본다
2. 써본만큼 어떤건 영어로 어떤키워드여야한다가 감이 잡힌다.
3. 많이 써보는게 좋을거같다. 그게 제일 중요하다고 생각하기 때문에

4. 이걸한번 느껴보는게 좋다
5. 실장님은 유리하다
6. 웹으로해도되고 뭐 다양하게 해도된다
7. 일단 채팅으로 구체화를 아이디어를
8. !중요 -> 바로 개발 X 시안을 뽑아야한다
9. 맘에 안들어서 뭐 수정할때 이미 개발이 많이 되어있으면 토큰낭비 + 느림
10. 이게 개발이 되어있으면 얘가 그걸 레퍼런스삼아버려가지고 + 자기 생각도 고착화 되버림
11. !중요 -> 프론트 부터 만들어라. 원하는기능은 프론트에 있고 그걸 구체화하려면 백이 있는거, 같은 맥락인데 백/프론트 다만들어놓고 시작하면 한기능 수정할때 오키?
12. 그럼 백부터? 프론트가 낫죠
13. 프론트했다고 쳤을때, 이제 백엔드를 가야지
14. 여기에 아키텍쳐까지 들어가면 더 좋은데 일단
15. 서버가 필요하다 이게 갈때이제 docker써주고 이걸 aws ec2처럼 쓰면 좋은데 docker를 쓰는게 일단 회사에서 안되기도 하고, 더 편할텐데
16. 복잡한건 이미지생성도 쓰면 좋은데, 이건 codex쪽만 가능하다
17. 레퍼런스가 있으면 더 잘만든다.
